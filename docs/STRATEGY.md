## 1. 인스타그램 vs Picto — 수익화 구조 비교

| | Instagram | Picto |
|---|---|---|
| 핵심 자원 | 무한한 콘텐츠 → 광고 지면 판매 | **희소한 사진 슬롯** → 슬롯 자체가 상품 |
| 돈 내는 사람 | 광고주 (사용자는 상품) | **사용자 (자발적 결제)** |
| 검증된 유사 모델 | — | Candy Crush 에너지, Discord Nitro, LINE 스티커 |
| 사용자 경험 | 광고가 경험을 해침 | 결제가 경험을 해치지 않음 (코스메틱/편의) |

### Picto 수익화 4단 로드맵

1. **지금 (라이브):** ❤️×5 = 📸 티켓 — *희소성 루프로 리텐션 확보* (수익화의 토양)
2. **v1.5 — Picto Plus (월 구독):** 프리미엄 이모지 팩 · 프로필 오라 · 부스트
   - 근거: Discord Nitro($9.99/월)의 절반이 코스메틱 동기. 텍스트가 없는 SNS에서 아바타/이모지 = **유일한 자기표현 수단** → 지불 의사가 오히려 높음
3. **v2 — 티켓 소액결제:** "기다리거나(무료), 사거나(유료)" — 모바일 게임에서 20년 검증된 구조
4. **v3 — 크리에이터 이모지 마켓 (제2의 수익화):** 작가들이 캐릭터 이모지 팩 판매, 수수료 30%
   - 근거: LINE 스티커 마켓은 연 수천억 규모. K-캐릭터(카카오프렌즈류) 감성은 글로벌 수출 검증됨
   - 보너스: **브랜드 스폰서 이모지** (영화 개봉 기념 팩 등 — 옛 Twitter 브랜드 이모지는 개당 $1M)

## 2. 트렌드 올라타기 — 무엇이 인기를 만드나

### ✅ 이번에 구현 완료
| 트렌드 | 기능 | 근거 |
|---|---|---|
| **데일리 리추얼** (Wordle, BeReal, Duolingo streak) | 📅 **오늘의 주제** — 매일 전 세계가 같은 질문에 이모지로 답함 | "매일 오는 이유"가 리텐션의 전부. 21개 주제 자동 순환, 서버 불필요 |
| **공유 가능한 결과물** (Wordle 녹색 격자) | 📤 **공유 버튼** — 이모지 캡션은 그 자체로 완벽한 공유물 (복사·붙여넣기 가능!) | 텍스트로 복사되는 콘텐츠 = 카톡/문자/트위터 어디든 침투 |

### 🔜 다음 우선순위 (피드백 보고 결정)
1. **🔥 스트릭(연속 출석)** — 오늘의 주제에 N일 연속 답하면 뱃지. Duolingo가 증명한 최강 리텐션 장치. 기존 스탬프 시스템 재활용 가능
2. **📊 "오늘 지구의 기분"** — 전 세계 무드 이모지 실시간 집계 대시보드. *언론이 기사 쓰기 좋은 데이터* → 무료 PR 머신 ("오늘 인류는 😴 상태입니다")
3. **⏳ 이모지 스토리 (24시간 소멸)** — 부담 없는 일상 공유, 기존 stories 페이지 재활용
4. **🧩 이모지 퀴즈 게임** — "이 이모지 조합은 무슨 영화? 🦁👑" 유저 출제 → UGC 게임 루프
5. **👨‍👩‍👧 가족 모드** — 호주 등 16세 미만 SNS 규제 강화 흐름 = "텍스트 없는 안전 SNS"에 순풍. 조부모-손주 전용 피드는 마케팅 각도로도 최고

### 포지셔닝 문장 (마케팅 전면에)
- 🇰🇷 "3초면 충분한 SNS" — 숏폼 피로 시대의 안티테제
- 🇺🇸 "The social network you can hand to your kid — and your grandma"
- PR 각도: 악플 원천 차단(이모지 전용) + 규제 순풍 + K-스타트업 스토리

## 3. 성장 플라이휠

```
오늘의 주제 📅 → 이모지 게시물 ✏️ → 반응 수집 ❤️ → 사진 티켓 📸
     ↑                                                    ↓
공유 버튼 📤 ← 자랑하고 싶은 순간 🎉 ← 희소한 사진 게시물
```

- 사진이 희소하므로 사진 게시 = 자랑거리 = 공유 동기
- 공유물이 이모지 텍스트라 어느 메신저로든 전파
- 신규 유저는 게스트로 3초 만에 합류 → 루프 재시작
